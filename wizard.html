📖 手把手教學：3 分鐘免費申請自己的 Firebase 即時資料庫

使用個人 Google 帳號即可免費使用 Firebase Spark 方案（免綁信用卡、無費用風險，1 班級使用綽綽有餘）。

🚀 前往 Firebase 主控台 ↗
1
登入並「建立專案 (Create a project)」
打開上方 Firebase 主控台 → 用您的 Google 帳號登入 → 點擊 「建立 Firebase 專案」 → 輸入專案名稱（例如 class-502-board）→ Google Analytics 可選擇「不要啟用（關閉）」→ 點擊「建立專案」。
2
開啟「Realtime Database（即時資料庫）」與永久規則
進入專案後，點選左側選單 「建構 (Build)」→「Realtime Database」 → 點擊 「建立資料庫」：
• 位置請選離台灣最近的 asia-southeast1（新加坡）。
• 安全規則先選 「以測試模式啟動 (Start in test mode)」 → 按「啟用」。
⚠️ 重要必做（避免 30 天後過期斷線）：建好後點上方「規則 (Rules)」分頁，改貼以下規則並按「發佈」： 
{
  "rules": {
    "hw_boards": {
      ".read": true,
      ".write": true
    }
  }
}
3
新增網頁應用程式（點選 </> 圖示）
點擊左上角「專案總覽 (Project Overview)」→ 點選頁面中央的網頁圓形圖示 </>（新增應用程式）→ 應用程式暱稱填 hw-board（不需勾選 Firebase Hosting）→ 點擊「註冊應用程式」。
4
整段複製 firebaseConfig 貼入下方輸入框
畫面出現 const firebaseConfig = { apiKey: "...", ... }; 後整段複製，直接貼進下方文字框！
💡 若該程式碼裡面沒有看到 databaseURL 欄位，請回到 Step 2 的 Realtime Database 頁面，把最上方顯示的 https://xxx.firebasedatabase.app 網址一起複製補進來，或先建好資料庫再註冊網頁應用！
